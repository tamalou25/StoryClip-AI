Paris Manif 3D

Prototype — incrément 1 : déplacement, caméra, commandes.

  • Ordinateur : ZQSD (AZERTY) ou WASD/flèches, A/E (Q/E en QWERTY) pour tourner la caméra, C pour recentrer, Espace pour l'action, Échap pour la pause.
  • Mobile : pouce gauche n'importe où à gauche = joystick ; glisser à droite = caméra (facultatif) ; boutons à droite.

Simulation de jeu fictive. Aucun lien avec des événements réels.
